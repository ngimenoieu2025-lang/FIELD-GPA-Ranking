\subsection{Implementation and Computing Setup}
\label{sec:methods-computing}

\guide{Adam -- Computing setup (two or three sentences)}{%
\textbf{State:} all analyses in Python 3.14 with NumPy, pandas, SciPy, statsmodels, scikit-learn and Matplotlib (versions in Table~\ref{tab:software}); run on a laptop with an Intel Core Ultra 7 258V processor (8 cores), 32~GB of memory and Windows 11, without a GPU; the whole pipeline takes about 16 minutes (without the US replication, whose data must be downloaded first), most of it in the Progress Report analyses (\texttt{progress.py}, about 6 minutes), the model tuning (\texttt{model\_selection.py}, 3.4 minutes) and the 1,000 bootstrap resamples of the ranking rules (3.3 minutes); random seed 42 everywhere, so a rerun reproduces every number and figure (we checked this by rerunning all scripts on a fresh copy). Point to Appendix~\ref{app:reproducibility} and the repository for the run order.}
